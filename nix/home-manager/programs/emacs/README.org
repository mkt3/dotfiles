* Overview
  This file is the literate source of the Emacs configuration.
  Home Manager tangles it into =config.el= while building the configuration generation.
  On startup, =init.el= loads that generated file directly without loading Org first.
  Changes therefore belong in =README.org=; =config.el= is a build artifact owned by Home Manager.

  Home Manager owns the Emacs build, tree-sitter grammars, platform-specific packages, and files needed before Emacs starts.
  =early-init.el= contains settings that must run before package and frame initialization.
  Most remaining packages are installed on demand by =use-package= from the archives configured below.

  The file-local variable on the first line opens this file read-only.
  Use =C-x C-q= before editing it directly in Emacs.

** Applying changes
   Run =make apply= at the repository root after changing Home Manager files.
   Home Manager regenerates =~/.config/emacs/config.el= when this file changes.

   To apply the new configuration in a running Emacs session, run =make apply= and evaluate =(load (locate-user-emacs-file "config.el") nil 'nomessage)=, or restart Emacs.
   Start Emacs with =EMACS_PROFILE_STARTUP=1= and run =M-x use-package-report= to inspect package startup times.

** Configuration boundaries
   Keep settings in the earliest layer that requires them:

   - =package.nix= selects the Emacs build and platform variant.
   - =default.nix= installs grammars, native packages, and files managed by Home Manager.
   - =early-init.el= configures package activation and the initial frame before normal initialization.
   - =README.org= configures built-in features and packages loaded by =use-package=.

   Credentials and machine-specific paths must come from environment variables or Home Manager rather than being embedded in generated Lisp.

                               (re-search-forward org-heading-regexp subtree-end t))
                     (let ((heading-position (line-beginning-position)))
                       (save-excursion

                   (org-back-to-heading t)
                   (org-end-of-meta-data t)
                   (unless (bolp) (insert "\n"))
                   (setq summary-position (point))
                   (insert (format "%s Clock summary\n"
                                   (make-string summary-level ?*))))
                 (set-marker subtree-end nil)
               (goto-char summary-position)
               (let ((summary-end (copy-marker (org-entry-end-position))))
                 (unless (re-search-forward
                          (format "^[ \t]*#\\+BEGIN: clocktable .*:block %s[ \t]"
                                  (regexp-quote date))
                          summary-end t)
                   (org-back-to-heading t)
                   (org-end-of-meta-data t)
                   (unless (bolp) (insert "\n"))
                   (insert
